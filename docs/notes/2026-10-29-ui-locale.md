# UI の言語を切り替える（#384）

## 受け入れ条件

1. 設定で言語を選ぶと、シェルと会話の固定文言がその言語になる。再読込しても残る。
2. 辞書に無い文言は、既定の言語のまま出て、空にはならない。
3. モデルに送るプロンプトの言語は、この設定では変わらない。

## 現状

Web の文言は各 component に英語で埋まり、言語を選ぶ口も辞書も無かった。日付は
`toLocaleDateString(undefined, ...)` でブラウザ任せ、相対時刻の「now」「yesterday」
も英語のままだった。

## 方針

- `apps/web/client-solid/locale.ts` に文言の表を 1 か所置く。`en` が完全な表で、
  追加の言語は部分表。`message(locale, key)` は `locale の表[key] ?? en[key]` を返すので、
  訳の無い行は既定の言語で出て、キー名や空欄にはならない。
- 初回は `localStorage` の `jzh.locale`、無ければ `navigator.languages` の対応言語、
  それも無ければ `en`。設定シートで選ぶと即座に切り替わり、`localStorage` と
  `document.documentElement.lang` に残す。
- `i18n.ts` の Solid context が locale と選び直す関数を配り、各 component は
  `useTranslate()` で表を引く。単体で描くテストは既定の `en` で動く。
- 日付は `Intl.DateTimeFormat`、大きな数は `Intl.NumberFormat` の `compact` で
  その言語の書き方にする。相対時刻の「now」「yesterday」も表に置く。
- モデルに送る prompt の組み立てには触れない。ブラウザは自分の文言だけを描き、
  言語の選択でサーバへ command を送らない。

## 残り

- composer の seat（model / effort / commands のチップ）と、右ペインの各 section
  （todo・skills・prompt・pages・plugins・schedules・share など）はまだ英語である。
  同じ表にキーを足し、その component で `useTranslate()` を呼べば切り替わる。
- `whenOf` の分・時は `5m` / `2h` のまま。言語ごとの単位にするなら表に足す。
