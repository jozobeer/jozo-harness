# エージェント構成エディタ（#400）

## 受け入れ条件

- 画面で、新しいセッションの既定に含めるツールの組を選べる。
- 開いているセッションの組を変えるときは、足りなくなったツールが分かるまで書き込まない。
- 変えたあとの次の turn が、選んだ組だけをモデルに出す。

## 方針

- セッションの組は session event としてログに残し、次の turn の tool 列に反映する。実行中の layer は差し替えない。
- セッションの変更は「足りない tool を先に返す」preview を挟んでから書く。足りないものが分かるまで書き込まない。
- 今後の既定は config file の口（既存の設定書き込み経路）に保存する。セッションの組と既定は別の操作。
- 秘密の値は扱わない。参照名だけ。
