# 推論の翻訳（#401）

## 受け入れ条件（issue 本文から）

- 展開した推論に、訳文を並べられる。
- ログに残る推論の原文は、翻訳の前後で変わらない。
- 翻訳できないときは原文だけが出て、失敗が原文を消さない。

## 方針

- 表示中の 1 つの推論（開いたターンの推論）を対象にする。セッション全体を訳すと、
  読まない推論までモデルに送ることになり、待ち時間と費用が読む量に比例しなくなるため。
- 訳文は原文とは別のイベントとしてセッションログに残す。原文の `reasoning` ブロックは書き換えない。
- 訳の生成はモデルへの 1 往復。失敗・オフラインでは原文だけを出し、理由を添える。

## 検証

- 文で書いた振る舞いテスト（モデルは stub / replay）。
- `pnpm run build:web` と `pnpm run check`。
