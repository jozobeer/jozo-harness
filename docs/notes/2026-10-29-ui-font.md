# フォントの種類と大きさを選ぶ（#386）

## 受け入れ条件

1. 設定でフォントの種類（サンセリフ / セリフ / 等幅）と基本サイズ（12〜18px）を選べ、会話と composer に効く。
2. 選んだ値は `localStorage` に残り、再読込しても同じ見た目で開く。
3. まだ選んでいないときは、変える前の見た目（サンセリフ 14px）のままである。
4. 選んだ face にかかわらず、コードとツールの出力は等幅のままである。

## 現状

テーマは `apps/web/src/ui/theme.ts` と `localStorage` の `jzh.theme` で選べたが、face と大きさは `apps/web/src/ui/style.css` の `--sans` と `--text-base: 14px` に固定され、選ぶ口が無かった。

## 方針

- `apps/web/src/ui/font.ts` に選べる face と大きさの閉じたリスト、保存値の読み方、face のスタック参照、大きさの倍率を置く。リストに無い保存値は既定（`sans` / 14px）に落とす。
- 大きさは px ではなく倍率（`size / 14`）にし、`--text-*` の各段を `calc(… * var(--font-scale))` にする。本文だけ変えて注記やボタンが取り残されるのを避ける。
- スタイルシートは `:root` に `--font-family: var(--sans)` と `--font-scale: 1` を持ち、body は `var(--font-family)` で組む。読者が選ぶと `document.documentElement` の inline カスタムプロパティが上書きする。未設定なら inline が無く、今の見た目と同じになる。
- `var(--sans)` を名指ししていた注記・見出し・ダイヤルの文字も `var(--font-family)` に変える。コードとツール出力は従来どおり `--mono` を名指しする。
- `dom.ts` が保存値の読み書きと DOM への反映を持ち、store の `start()` が起動時に適用する。設定シートの `font` / `text size` は選ぶとその場で適用し、`jzh.font.family` / `jzh.font.size` に残す。

## 残り

- 実ブラウザでの目視は、この作業を行った sandbox にはこの checkout の Web UI が無いため行っていない。テストと `build:web` の出力で確認した。
- 選べる face は閉じた 3 種類である。増やすときは CSS のスタック（`--serif` の隣）と `FONT_FAMILIES`、locale のラベルを揃える。
- この選択はブラウザのページだけで、TUI と CLI の出力には効かない。
