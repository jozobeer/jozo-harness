# Web 設定画面で鍵・タイムアウト・委譲・検索を編集する（#385）

## 受け入れ条件

1. Web の設定画面から検索プロバイダの鍵の有無を切り替えられる。値そのものは画面にもログにも残さない。画面が扱うのは参照名（credentials のキー名）だけである。
2. bash の既定タイムアウト、同時に走るツール数、委譲する子の深さを画面で変えると、次の呼び出しから効く。
3. 委譲（delegate）で子に渡す tools を画面で編集できる。
4. ファイルを直接編集した値と画面の値が食い違わない。読み書きは既存の config-file の口に寄せ、出どころは dump と同じ規則にする。
5. 保存は既存のゲート（origin / cookie / token）を通す。
6. 不正な値は保存せず、どの項目が悪いかを返す。

## 方針

- 設定の読み書きを 1 か所（既存の config-file の口）に寄せる。
- 秘密の実体は credentials に置き、設定ファイルには参照名だけを書く。
- 画面とファイルの双方が同じ正規化を通るようにする。

## 検証

- 振る舞いを文で書いたテストを足す。
- `pnpm run build:web` と `pnpm run check` を通す。
