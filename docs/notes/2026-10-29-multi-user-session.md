# 複数人で同じセッションを操作する（#382）

## 受け入れ条件

1. 所有者が発行した参加で、他のブラウザが同じセッションの会話を見て入力できる。
2. 参加を切ると、そのブラウザは操作できなくなる。
3. 参加者が増えても、ログの書き手は一つに見える。

## 現状

Web は複数端末から同じサーバへ繋げるが、合言葉は起動時に発行される
1 本のトークンだけで、所有者が他人に操作を渡す単位も、渡した相手だけを
止める単位も無い。セッションのログは 1 本で、入力はすべて同じ
セッションの host が受け取るため、書き手は既に一つである。

## 方針

- 所有者（起動トークン）が参加を発行する。参加は id・ラベル・役割・
  トークンを持ち、役割は会話を見るだけの `viewer` と入力できる
  `operator` の 2 つ。発行と失効は実行中だけ覚える。
- ブラウザは参加トークンを `?join=` で渡し、WebSocket と読み取りの
  門は参加トークンでも通す。失効した参加のトークンは次の要求から
  通らない。
- 参加者の入力も同じセッションの host に渡す。ログを書くのは
  セッションであって接続ではないため、書き手は一つのまま。
